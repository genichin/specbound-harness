# MS-0001-004 — Delivery-QC aggregation contract

## Objective

Satisfy **REQ-0001-r1 AC-004** by making one canonical delivery-QC record a fail-closed aggregation of a single approved REQ snapshot and the verified canonical iteration-QC evidence that covers every current parent acceptance criterion.

## Scope

- Extend delivery-QC v1 validation beyond AC-001 topology/envelope validation.
- Require exact canonical approved REQ path, ID, revision, and SHA-256 binding derived from the delivery-QC filename.
- Require every parent REQ acceptance criterion to map to one or more verified canonical iteration-QC snapshots that select that criterion and are bound through their canonical Micro-SPEC to the same parent REQ snapshot.
- Require digest-bound iteration-QC references, reproducible cross-iteration regression evidence, a policy-allowlisted QC reviewer/delegated authority, and an explicit unresolved-exception/residual-risk disposition.
- Fail closed for incomplete/unknown coverage, stale or cross-REQ iteration evidence, non-verified iteration verdicts, absent regression evidence, malformed residual-risk disposition, unauthorized authority, and merge/delivery/release authority claims.
- Add valid and copied-fixture negative coverage; update the delivery-QC schema/template, configuration policy, documentation, and repository skill.

## Non-goals

- Do not implement adoption enforcement, canonical artifact issuance, merge authorization, delivery execution, release execution, or release provenance (AC-005 and AC-006 remain out of scope).
- Do not issue, rewrite, or relabel approval, REQ, manual-bootstrap, or iteration artifacts.
- Do not treat a delivery-QC record or its reviewer authority as authorization for delivery, merge, or release.

## Baseline

AC-001 enforces delivery-QC topology and JSON `schema_version: 1`. AC-002 and AC-003 define the canonical Micro-SPEC and iteration-QC bindings that delivery-QC aggregates. Existing root artifacts remain manual-bootstrap and deliberately non-canonical, so isolated copied fixtures prove the canonical aggregation contract.
